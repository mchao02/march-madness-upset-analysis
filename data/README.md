# Data
This project uses historical NCAA men's basketball tournament results, tournament seeds, and detailed regular-season statistics.

## Source
Doanloaded from: https://www.kaggle.com/competitions/march-machine-learning-mania-2025

## Required Files
- MNCAATourneyCompactResults - Tournament game results, including winning and losing teams and scores
- MNCAATourneySeeds.csv - Tournament seeds for each team by season
- MREGULARSeasonDetailedResults.csv - Regular-season box score statistics used to calculate team performance metrics

## Setup
1. Download the dataset from the source linked above
2. Extract the three CSV files listed
3. Place them directly into this data folder without change the file names
4. Run python main.py from the main project folder
